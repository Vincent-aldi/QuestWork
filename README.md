# QuestWork

Aplikasi manajemen tugas berbasis gamifikasi (quest, EXP, level, dan reward) untuk sisi karyawan.

### Fitur yang bisa diuji
- Login karyawan
- Daftar tugas (Papan Misi) dan detail tugas
- Dashboard, leaderboard, Hall of Champion, dan reward
- Profil dan ubah profil

### Cara instal
1. Unduh file `QuestWork-v1.0.0.apk` di bagian **Releases**.
2. Buka file di HP Android, lalu izinkan **"Instal dari sumber tidak dikenal"** jika diminta.
3. Jika muncul peringatan Google Play Protect, pilih **Tetap instal**.

### Syarat pengujian
- HP harus terhubung ke **WiFi yang sama** dengan server backend.
- Server backend harus dalam keadaan menyala.
- Hanya untuk Android.
